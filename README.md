# Qasr landing page

A single-page, mobile-first company site built with plain HTML, CSS and JavaScript. It presents Qasr's website, app, ERP and payment system services and is ready to publish from the repository root with GitHub Pages.

## Files

- `index.html` — page structure and editable example content
- `styles.css` — colors, components and responsive layout
- `script.js` — mobile navigation and scroll reveal

## Before publishing

Replace the sample project names, descriptions, outcomes, founder names and client wordmarks in `index.html` with approved company details. The Arabic Qasr lettering in the wordmark is a text-based logo using the Amiri font. Add the correct WhatsApp number to the `wa.me` link in the contact section. The English page is marked `lang="en" dir="ltr"`; for an Arabic version, add a translated page with `lang="ar" dir="rtl"` and review directional spacing and icon alignment.

To publish, choose **Settings → Pages** in the GitHub repository, select the branch and `/ (root)` folder, then save.
